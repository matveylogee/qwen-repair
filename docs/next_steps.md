# После M0

M1 начинается по отдельному заданию пользователя. M0 завершает локальную проверку протокола; его синтетические метрики не подтверждают качество модели или работоспособность обучения.

1. Сохранить код в выбранном Git remote и выбрать точный commit для Colab. Открыть `notebooks/00_preflight.ipynb`, указать URL и SHA, выполнить CPU doctor и fake demo.
2. Для реального inference выбрать GPU runtime в настройках Colab. Проверить доступную GPU, VRAM, Python, torch/CUDA и свободный диск; по фактической среде зафиксировать GPU-зависимости. Текущий CPU doctor не является такой проверкой.
3. Подключить `Qwen/Qwen3-0.6B`, закрепить revision модели и tokenizer, применять chat template с `enable_thinking=False`. Заменить счётчик байтов реальными token IDs и проверить одинаковый формат сообщений в обучении и оценке.
4. Реализовать изолированный executor и его preflight: ограничить сеть, файлы, процессы, память, время и вывод. Не выполнять внешний reference или ответы модели на основной машине. Доступность Docker или namespaces в Colab проверить на месте; если изоляция не работает, испытать очередь к локальному Docker worker на одном запросе и небольшой пачке.
5. Взять небольшой KodCode-срез с закреплённым revision. Проверить схему, тесты и reference в executor; выделить public/private cases и разделить исходные группы до мутаций. Полный импорт и массовая обработка пока не нужны.
6. Выполнить короткий SFT smoke-test, проверить masks и загрузку адаптера. Затем проверить несколько настоящих multi-turn GRPO update: одинаковую задачу внутри группы, зафиксированную policy до завершения группы, action masks и logprobs. Успешный однократный inference не заменяет эту проверку.
7. Проверить сохранение и восстановление в новом процессе, включая optimizer/RNG/data cursor. Измерить VRAM, скорость генерации, время эпизода, executor и checkpoint. По измерениям выбрать масштаб пилота.

До настоящего обучения отдельно проверить, что hidden feedback не влияет на prompt, stopping или выбор кандидата, а инфраструктурные сбои не получают reward=0. Проверки M0 останутся регрессионными тестами протокола, но не заменят preflight нового backend.

В M0 не выбраны и не проверены версии GPU-стека, Colab runtime или изолирующего backend. Нужны доступ к выбранному Git remote и Colab, доступная GPU и решение по месту исполнения тестов. Публикация данных, длительное обучение и платные сервисы не входят в текущую итерацию.
